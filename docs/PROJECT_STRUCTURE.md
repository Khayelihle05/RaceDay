# RaceDay Project Structure

## Overview

The RaceDay repository is organised to keep the project documentation, database planning and CI/CD configuration easy to locate and maintain.

## Folder Descriptions

### .github/workflows

Contains the GitHub Actions workflow used to validate the RaceDay repository structure.

### docs

Contains the Part 1 planning and database documentation, including the ERD, API Endpoint Plan and SQL Server script.

### Root Directory

Contains the main project README, Git configuration files and the successful CI/CD workflow screenshot.

## Part 1 Organisation

The repository structure keeps the required RaceDay planning documents together inside the `/docs` directory and provides supporting documentation for the project.
