# RaceDay Seed Data

## Overview

The RaceDay SQL script includes sample seed data so that the database can be tested immediately after creation.

## Users

The database includes:

- 2 Organisers
- 2 Participants

These users are used to test event creation, enrolments and results.

## Event Types

Sample event types include:

- Running
- Walking
- Cycling

## Locations

Sample locations are included for events taking place in South Africa.

Examples include locations in:

- Pretoria
- Johannesburg
- Durban

## Events

The database includes at least 3 sample events.

These include:

- Pretoria City Run
- Johannesburg Charity Walk
- Durban Coastal Cycle

## Categories

Each event includes sample categories.

Examples include:

- Open categories
- Junior categories
- Different event distances

## Enrolments

Sample enrolments are included to demonstrate how Participants enter events and select categories.

## Results

Sample result data is also included to demonstrate how an Organiser can capture a Participant's event result.

## Purpose

The seed data allows the RaceDay database structure and relationships to be tested without requiring all records to be entered manually.
