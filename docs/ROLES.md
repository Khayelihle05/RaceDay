# RaceDay User Roles and Permissions

## Overview

The RaceDay Event Management System uses role-based access to control what users are allowed to do within the system.

The two main user roles are Organiser and Participant.

## Organiser

The Organiser is responsible for creating and managing RaceDay events.

An Organiser can:

- Create new events.
- Edit existing events.
- Delete events.
- Create and manage event categories.
- View participant enrolments for events.
- Capture participant results.
- Update participant results.

## Participant

The Participant uses RaceDay to discover and enter events.

A Participant can:

- Create an account.
- Log into the system.
- View and update their profile.
- Browse available events.
- View event categories.
- Enrol in an event.
- Select an event category during enrolment.
- View their existing enrolments.
- View and track their event results.

## Role-Based Access

RaceDay will use role-based access control to ensure that users can only access functionality permitted for their role.

Organiser-only operations, such as creating events and capturing results, will be restricted to Organiser accounts.

Participant-specific operations, such as entering an event and viewing personal enrolments, will be restricted to Participant accounts.
