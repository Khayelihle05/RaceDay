# RaceDay Documentation

This folder contains the planning and database documentation for Part 1 of the RaceDay Event Management System.

## Included Documents

- **RaceDay ERD**  
  Shows the database entities, attributes, primary keys, foreign keys and relationships.

- **API Endpoint Plan**  
  Defines the planned API routes, HTTP methods, user roles, request bodies and expected responses.

- **RaceDay Database SQL Script**  
  Contains the SQL Server database creation script, constraints and sample seed data.

## Main Database Entities

The RaceDay database includes:

- USERS
- EVENT
- EVENT_TYPE
- LOCATION
- CATEGORY
- ENROLMENT
- RESULT

## Purpose

These documents form the planning foundation for the RaceDay system and will be used during the API and MVC implementation stages of the project.
