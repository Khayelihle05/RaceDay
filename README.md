# RaceDay Event Management System

## System Description

RaceDay is a full-stack event management system designed for South African running, walking and cycling events. The system allows organisers to create and manage events while allowing participants to browse events, enrol in event categories and track their results.

## User Roles

### Organiser
Organisers are able to:
- Create, edit and delete events.
- Manage event categories.
- View participant enrolments.
- Capture participant results.

### Participant
Participants are able to:
- Create an account and manage their profile.
- Browse available events.
- Enrol in an event and select a category.
- View their event enrolments.
- Track their event results.
